# Columbia Pupin Hall：校园侧四处主屋面延伸接缝

在上一批四片主屋面的基础上，沿建筑长向增加四片实测支持屋面，水平投影合计 7.30 m²，与旧网格以共用顶点和共用边焊接约 5.84 m。不是独立浮面：FBX 回读确认每条接缝的两侧三角面使用同一顶点索引、邻面绕序相反。三档合计三角面 1125 / 693 / 597；每档 4 个旧屋面对象增 12 面，旧四片的形状保持（最大回读高度变化 0.012 mm），为四个改动对象重排连续的诊断 UV，另外 36 个网格对象的顶点、面、UV、材质与角法线签名逐项未变。

实际补齐范围：面向中心两片 |U|=15.65–16.90 m、V=−7.15 至 −6.18 m；面向两端两片 |U|=24.40–25.65 m、V=−7.15 至 −5.20 m。坐标沿用 U/V 局部框架和 Z0=35.705 m NAVD88。使用 2017 NOAA EPT 9306 同一云中的新空间范围，按源编号 1100 两侧保持组别；278 个范围内符合首回波 class 1 的点全部纳入，不按残差剔除。复用既有坡面，未对本批点重新拟合；FBX 回读每个分组最大 P95 0.1831 m、最大单点差 0.1969 m，最稀疏分组到候选范围的最大近邻距离约 0.615 m。不是跨期复测，不是材料证明。

Blender 4.3.2 重读三档，3,840 处接缝三点验证（沿边中心及 ±0.6 mm），最大高度偏离接缝 0.023 mm，未发现裂隙；8,704 处新增面内部位置三档共同命中。新增面未与其他旧对象相交。往北之后的点云不再支持延用同一斜坡，往檐端也分成多层高程，因此保留外边、不补檐口、天沟、窗墙或无测点连片。此为局部屋面试件，不是整栋建筑；没有生产材质替换、CS2 Editor 验收或 pmod 发布。

复验：解压后 sha256sum -c SHA256SUMS.txt；运行 python guard.py verify.py -- "$PWD"。result/ 是本版；prior/ 是上一版原样，用于复验；witness.npz 保留本批全部 278 个空间复核点。重新拟合的脚本只作点云选择，如需复做选址须单独有上一包的点云及原坡面参数。
