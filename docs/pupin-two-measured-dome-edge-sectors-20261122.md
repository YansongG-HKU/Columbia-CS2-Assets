# 哥大 Pupin Hall：大穹顶边缘两处实测支持斜面

大穹顶上一版核心止于半径 3.10 m。本批只把两处各 60° 的边缘沿斜面延至 3.40 m 和 3.46 m（U 向为 0°，朝 +V 为正），投影约 2.26 m²，沿既有穹顶焊接约 6.48 m。原有面索引、顶点坐标和 UV 精确保留；三档里另外 45 个网格签名不变。旧穹顶面角法线最大读取变化约 0.022°。整套局部屋面三档输出 1157 / 709 / 613 三角面。

新增范围内同一 2017 NOAA EPT 9306 的 70 条 class 1 首回波均纳入分析，按采集编号分两组互相验证，新坡面内边固定为原穹顶外缘，不按残差剔除。分组互留最大 P95 约 0.327 m，最大单点差 0.391 m，分组内最远样点支持距离约 0.500 m。FBX 回读对圆边折线外的 4 条临界样本在 LOD1/2 分开标记，实际命中点分组 P95 最大 0.304 m。不是跨期复测，也不是裙边、鼓座或开合盖的测量。

三档 FBX 重新导入后，共检 1248 处接缝三点（边上和两侧各 0.5 mm），确认每条焊接边由两侧面共用而不是重叠两个对象。检测点相对边高最大 0.692 mm；4582 个三档共同测试位置的档间差 P95 6.23 cm，最大 10.21 cm，保留旧 LOD 外缘的原有简化差异，未认证游戏换档视觉。新增面不与其他对象相交。
