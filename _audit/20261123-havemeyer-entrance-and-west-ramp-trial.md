# 哥大 Havemeyer Hall｜带铭牌的主门与独立西坡道三档整栋

从 HavemeyerHallTrial/ 独立导入；原枢轴与 8×8（64×64 米）保留，−Y 是校园南面。近、中两端的屋檐各约有 0.55 米悬出，摆放时需核相邻地块。

- 参考[哥大化学系门口照片](https://www.chem.columbia.edu/sites/www.chem.columbia.edu/files/content/pics/graphics/NewsletterFall21/2021%20Fall.pdf)及[2021 校园工程回顾](https://cufo.columbia.edu/sites/cufo.columbia.edu/files/content/March%202021%20Morningside%20Campus%20Presentation_Web.pdf)，以双红石柱、矩形双门、HAVEMEYER 铭牌、低栏和双球灯替代旧四柱和假拱。灯球以不透明模型表示，未配置发光。主门三阶为闭合网格，台阶顶模型分别为 7.14、7.28、7.42 米。
- 独立西门中心比主门向西偏 9.144 米，与[校方 2019 坡道项目说明](https://designconstruct.cufo.columbia.edu/content/havemeyer-hall-accessible-ramp-and-entryway)所述 30 英尺一致。从东向西坡面约升 0.413 米，坡段模型长 5.15 米，西台再转向侧门。远档原群体平台由 8.00 改到 7.00 米，与近中平台对齐。坡长度/高差是模型试放值，不是测绘或无障碍合规结论；旧外围大台基仍是简化体。
- 三档主体 72,504 / 40,260 / 556 三角，近中各另有 939 个窗三角。原门饰近/中各剔除 8,802/7,386 三角；别处原网格/UV保留，遗留塌缩 UV 尚未整体修复。远档主体平面改用面法线，纹理只改原图集未使用区。原档玻璃灯罩已被新灯替代，不把旧玻璃文件混入。
- 先核真实地形是否保留 7 米平台和西侧路径，再独立核对两个门的碰撞、游戏行人、三档切换与夜景。本版没有 Chandler 3/6 层连通、室内台阶、游戏导航或发布。附图是 Blender 回读，不是 pmod。

三档共验证 189 个坡面、36 个西门平台、60 个主门台阶、48 个侧门表面和 45 个主门铭牌采样。各档台阶 42 边、坡体 24 边均两面相接。这些仅为 FBX 几何检查。


原 main 固定 `98587eeddab6ddf83a0c562efbf449207d633582`，7 FBX 与 10 PNG 按 Git 对象和 LFS指针回核，未混用旧 160 triangle 仅色图的单独试验。最终 ZIP 9,037,287 bytes，SHA-256 `98f67be112c381c9ba4b8c8a80a5d05cf878d62f6c8ea0c0e2fc0a5afcabee31`，CRC、21 份内部哈希用解压副本通过。本记录只在草稿；模型未推送，主分支、外部发布和游戏验收没有变化。
