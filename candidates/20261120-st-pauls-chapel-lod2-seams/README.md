# St. Paul's Chapel far-mesh seams (offline candidate)

Source: Columbia draft 4d39597999f3729f4cddd288379d71ef1e9d1e5a, the canonical StPaulsChapel split LOD2 FBX. A bounded scan of all 19 canonical split LOD2 meshes found three pairs of opposing congruent rectangle caps, all at this asset. This does not assert absence of any other overlap, and the optional dark/ duplicate is excluded.

At local heights 15.0 and 10.2 metres the cap rings are congruent and opposing, four perimeter neighbors connect away from the plane on each side, and no other coplanar triangle or non-coplanar triangle in the source crosses the open cap interior. The candidate removes those eight internal faces and joins eight coincident vertices without any position change. The 13 m candidate contacts 16 other triangles inside the cap footprint and was left untouched. See ring-probe.log for boundary evidence. Geometry after export is 608 triangles (was 616), 336 vertices (was 344), 16 indexed components (was 18) and 912 consistently oriented two-face edges. Bounds are unchanged. All retained corner UVs, normals and tangent frames are copied, not recalculated.

A separate clean Blender 4.3.2 import and front/rear/aerial comparison used the unchanged 1024-square BaseColor and normal maps, explicitly loaded from their verified source hashes. There was no silhouette or unlit-color difference in those views; maximum lit-channel change was 5/255. This manually binds the source maps for comparison, not an FBX texture-path portability or editor import test. Texture bytes were not changed. See JSON readback and comparisons.

To replay with Python and zstandard: python model_delta.py apply /path/to/checkout /path/to/new-scratch . (from this folder). Ensure the source path contains the real LFS binary. The tool checks all three digests plus output size and writes a separate candidate. This has not been imported into Cities: Skylines II. Neither the canonical files nor the published package have been replaced.
