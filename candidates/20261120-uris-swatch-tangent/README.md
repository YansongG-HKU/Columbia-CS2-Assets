# Uris 两种色样的 FBX 切线候选修复

针对前一批确认有中性法线值 (128,128,255) 的两个金属色样。实际 FBX 的无效存储切线（零向量、不归一或不正交）不是推断：近、 中档这两组角点分别有 2580 / 1836 处。固定原法线图和上一批可移植 FBX 的 SHA-256，逐角保留原法线、已有合理方向和可靠手性信息，仅为失效框架构造规范切线/副切线，必要时用原法线的稳定正交方向。原 UV 仍用同一色样（不是新展图），不会重新投射贴图。未修改北侧、其他部件或未归类角点。

二进制逐角复核这两组存储切线的无效数为零，其他角点、原 UV/网格/法线/材质/路径相同；两件候选均从干净目录 Blender 4.3.2 回导，定位、拓扑、UV、法线、材质与原件相同。带哈希门槛的重放再次生成逐字节一致的候选。Blender 回导不保证 CS2 使用而非重算存储的切线，且未做游戏测试和贴图 mip 渲染验收，仍是独立诊断候选；没有改原文件或接缝。

剩余单点 UV：近 772（三角分 295 坐标），中 336（82 坐标）。每个坐标都精确匹配同档可编辑网格中一个有效 UV 面的多边形中心，与源烘焙的吸附机制一致，不是 FBX 导出才塌缩；这不证明来源材质相同或游戏光照正确。下一步按面积、材质和是否共享邻面检查，勿批量重展。云 Blender 退出后可用内存 8855 MiB。

复现：按 `../20261120-uris-import-portability` 先重建近与中档 FBX，每次运行 `blender -b -t 2 --disable-autoexec --python-exit-code 1 --python repair_uris_swatch_tangent.py -- near <已固定的近档FBX> <全新候选FBX> <全新报告JSON>`，中档用 `mid` 参数。原 Normal 图放原 FBX 同目录。
