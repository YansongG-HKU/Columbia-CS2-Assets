## Offline reproduction

Put the target building GML and footprint beside the scripts. The GML is extracted with extract_da13_lerner.py from inclusive ZIP byte range 130249474–174447202; see extraction.json. Use NOAA listing and ept-receipts.json to scope the 29 referenced tiles and the included EPT crop extraction grid. The resulting source files are lerner-ground-roofs.csv.gz and lerner-ground-roofs.json (not committed as data archives); see measurements.json for received SHA and the explicit crop and bands. Run OPENBLAS_NUM_THREADS=2 /usr/bin/python3 build_lerner_shell.py (GDAL/GEOS, numpy, pyproj) from the folder, resulting in deliver/ output. The evidence OBJ in this directory must match the generated SHA. shell_core.py regenerates the historical reference for validation. validate_render_lerner.py takes the two OBJ paths, old 72-triangle FBX, and an output directory, in that order.
